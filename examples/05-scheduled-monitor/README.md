# 05 — Scheduled AI Monitor

## Objective

Build an autonomous monitor similar to the reference video's YouTube example.

Suggested prompt:

```text
Monitor AI productivity trends.

Search for new developments on a recurring schedule.
Keep track of what you have already reported.
Only notify me when there is meaningful new information.
Use my configured home messaging channel for notifications.
```

Start conservatively. Verify:

1. The schedule exists.
2. The prompt is correct.
3. The job runs.
4. Memory prevents duplicate reporting.
5. Notifications arrive only when appropriate.
