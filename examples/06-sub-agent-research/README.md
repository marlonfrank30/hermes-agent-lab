# 06 — Sub-Agent Research

## Objective

Exercise Hermes delegation.

Example:

```text
Research the current AI agent landscape.

Use separate sub-agents to investigate:
1. Open-source agent frameworks
2. Commercial agent platforms
3. Local model agent stacks
4. Security considerations

Combine the findings into one concise technical report.
```

The main agent should coordinate the work and synthesize the final answer.
