# Hermes vs OpenClaw

The authoritative comparison is maintained at the bottom of the root `README.md`.

V5 deliberately uses conservative language. A capability is described as a Hermes advantage only when it is documented by Hermes and an equivalent first-class OpenClaw capability was not found in the current public documentation reviewed on September 1, 2026.

The most notable current Hermes differentiators documented in this repository are:

1. Script-only cron / `no_agent` execution with zero LLM involvement for deterministic jobs.
2. A broader named terminal-backend matrix, including Singularity, Modal, Daytona and Vercel Sandbox.
3. FTS5 session search with LLM-assisted summarization for cross-session recall.

The comparison also explicitly records areas where the two projects have converged, including memory, skills, self-learning, sub-agents, computer use, MCP and messaging.
