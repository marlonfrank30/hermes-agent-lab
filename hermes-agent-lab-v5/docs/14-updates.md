# 14 — Updates

Hermes changes quickly.

Use the current official Hermes documentation for:

- installation
- configuration
- desktop application behavior
- provider support
- model names
- channel integrations
- skill behavior

Do not assume screenshots or commands from the reference video remain identical.

The repository intentionally separates:

```text
Reference Video
      ↓
Conceptual Workflow

Current Hermes Documentation
      ↓
Installation / Current Behavior

Marlon's Config
      ↓
Actual Local Deployment

This Repository
      ↓
Reproducible Documentation + Labs
```
