# 06 — Desktop Access

The reference video uses the desktop application as another interface to the same remote agent.

The important concept is:

```text
Desktop
   |
   v
Remote Gateway
   |
   v
Existing Hermes Agent
```

Avoid unintentionally creating a second independent agent if your goal is a single persistent agent.

The exact desktop onboarding screens may change with Hermes releases. Follow the current application documentation for the installed release.
